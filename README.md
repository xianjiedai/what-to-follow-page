# What to Follow in In-Context Imitation Learning

Project page for the paper *What to Follow in In-Context Imitation Learning*, which introduces
**OPTIC** (Object-or-Position Tests for In-Context imitation learning).

**Project page:** https://xianjiedai.github.io/what-to-follow-page/

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Contents

- `index.html`: the page
- `static/css/`, `static/js/`: styles and scripts
- `static/images/`: figures from the paper and university logos
- `static/videos/`: rollout videos
